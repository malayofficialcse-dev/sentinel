# Sentinel — Phishing URL Detection

## Dataset
PhiUSIIL Phishing URL Dataset

## Objective
Train a machine learning model capable of classifying URLs as:

- 0 → Phishing
- 1 → Legitimate

## Pipeline

Dataset
    ↓
Data Validation
    ↓
Exploratory Data Analysis
    ↓
Data Cleaning
    ↓
Feature Selection
    ↓
Train/Test Split
    ↓
Logistic Regression
    ↓
Random Forest
    ↓
XGBoost
    ↓
Model Evaluation
    ↓
Best Model
    ↓
Model Artifact
