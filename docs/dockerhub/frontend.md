# Sentinel Frontend

React and TypeScript web interface for Sentinel investigations, served by
Nginx with API requests forwarded to the backend.

Pull: docker pull malaymaity/sentinel-frontend:latest

From the source repository, run docker compose up -d and open
http://localhost:8080. Compose starts the frontend, API, AI service, and
datastores.

Source: https://github.com/malayofficialcse-dev/sentinel
